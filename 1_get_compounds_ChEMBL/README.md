
# ChEMBL Data Retrieval

This repository provides scripts and methodologies for retrieving data from the **ChEMBL API**.

---

## **1. Data Retrieval from ChEMBL**  

The dataset used in this project was retrieved from **ChEMBL**, a database of bioactive molecules with drug-like properties. Data extraction was performed via the **ChEMBL API**, enabling programmatic access to compound, bioactivity, and target information.  

### **Dependencies**  
To interact with the ChEMBL API and retrieve relevant bioactivity data, install the required Python libraries:  

```bash
pip install chembl_webresource_client pandas requests tqdm
```
